=== ОНОВЛЕННЯ ==================================================

Checkout уже знаходиться на live-сервері. Не копіюйте файли з іншого хоста
й не перезапускайте сервіс окремо.

З кореня проєкту запустіть команду, яку наведено у фінальному звіті:

bash /home/igor/calories-bot/run_update.sh "<короткий опис змін>"

Скрипт додає дозволені файли до Git, створює commit за наявності змін,
надсилає його до origin, перезапускає calories-bot і перевіряє стан сервісу.

=== ПЕРЕВІРКА ПЕРЕД ОНОВЛЕННЯМ ================================

cd /home/igor/calories-bot
bash scripts/run_tests.sh

Paid LLM eval запускайте лише після окремого явного погодження:
bash scripts/run_tests.sh --llm --confirm

=== ДІАГНОСТИКА =================================================

Статус       sudo systemctl status --no-pager calories-bot
Активний?    sudo systemctl is-active calories-bot
Логи (100)   sudo journalctl -u calories-bot -n 100 --no-pager
Логи наживо  sudo journalctl -u calories-bot -f

Вийти з live-логів: Ctrl+C

=== НАЛАШТУВАННЯ ================================================

Редагувати    nano /home/igor/calories-bot/.env
Права         chmod 600 /home/igor/calories-bot/.env

Після зміни конфігурації застосуйте її через run_update.sh. Не додавайте до
Git .env, service-account.json, data/ або spreadsheet exports.

=== SYSTEMD UNIT =================================================

Після ручної зміни /etc/systemd/system/calories-bot.service:

sudo systemctl daemon-reload
sudo systemctl restart calories-bot
sudo systemctl status --no-pager calories-bot
