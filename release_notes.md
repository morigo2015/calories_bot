# Release notes

## 1.1.0 — 2026-08-14

### Додано

- Лише для адміністратора доступна команда `/burned` із витратою калорій
  Garmin за останні сім завершених днів.
- Дані Garmin завантажуються один раз на початку бот-доби (типово о 01:00),
  зберігаються в приватному локальному кеші й не запитуються під час виконання
  команди.
- Після перезапуску бот надолужує добове оновлення, якщо воно ще не відбулося.

## 1.0.3 — 2026-08-13

### Змінено

- Після видалення картка страви показує лише `Видалено` та назву
  страви, без денного підсумку.
- Бот видаляє всі застарілі денні підсумки нижче видаленої картки.
- Наприкінці чату надсилається один актуальний підсумок із заголовком
  `Оновлено після видалення`.
- ID денних підсумків зберігаються в SQLite, щоб очищення працювало після
  перезапуску бота.

## 1.0.2 — 2026-08-13

### Виправлено

- `/info` явно показує загальну кількість запитів і розбивку по
  кожному користувачу; в облік також потрапляють дії з inline-кнопками.
- Денний підсумок надсилається окремим повідомленням після картки
  страви та її кнопок.
- Для складеної страви денний підсумок показується один раз після
  всіх компонентів.
- Формула розрахунку калорій виводиться з нового рядка без дужок.

## 1.0.1 — 2026-08-12

### Додано

- Розширену адміністраторську статистику в `/info`: час останнього запуску,
  повідомлення за 24 години та 30 днів загалом і по користувачах.
- Облік вхідних, вихідних і кешованих OpenAI-токенів та їх розрахункової
  вартості за останні 30 днів.
- Прямий запит фактичної вартості до OpenAI Costs API за наявності
  `OPENAI_ADMIN_API_KEY`; `OPENAI_PROJECT_ID` обмежує суму поточним проєктом.

### Покращено

- Операційна статистика зберігається локально в SQLite та не втрачається після
  перезапуску бота.

## 1.0.0 — 2026-08-11

### Додано

- Облік версії застосунку та адміністраторську команду `/info`.
- Кнопки швидкого вибору ваги; стандартні значення задаються через
  `MEAL_WEIGHT_PRESETS`.

### Змінено

- Складена страва записується та показується окремо за кожним компонентом.
- Кожен компонент має власні кнопки збереження, зміни ваги та видалення.
- Збережені й нещодавні страви містять тільки однокомпонентні записи.

### Покращено

- Старий журнал калорій збережено для денних і тижневих підсумків, але старі
  записи не потрапляють до нового переліку нещодавніх страв.
- Старе сховище збережених страв одноразово очищується при переході на нову
  покомпонентну схему.
